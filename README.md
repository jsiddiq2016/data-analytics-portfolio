# data-analytics-portfolio
Portfolio of data analytics projects: SQL, Python, Power BI

By Javeria Siddiq

Welcome! This portfolio showcases data analytics projects completed using **SQL, Python, and Power BI**.  
With a strong foundation in mathematics and statistical analysis, these projects demonstrate skills in:

- Data cleaning and preparation  
- Exploratory data analysis (EDA)  
- SQL querying and relational database analysis  
- Dashboard development and data visualization  
- Translating data into actionable business insights  

---

## Projects

### 1. Transforming New-Wheels Sales and Customer Satisfaction (SQL)

Analyzed sales and customer feedback data using MySQL to uncover customer sentiment patterns and sales performance trends.  
Implemented multi-table joins, subqueries, group-by aggregations, and analytical functions to generate insights that support data-driven business improvement.

**Tools & Skills:** SQL, MySQL, Joins, Subqueries, Analytical Functions, Trend Analysis  

---

### 2. FoodHub Order Analysis (Python)

Performed exploratory data analysis on food delivery order data for a restaurant aggregator platform.  
Evaluated cuisine and restaurant demand, delivery time efficiency, and customer ratings to provide business recommendations that improve customer experience and support revenue growth.

**Tools & Skills:** Python, Pandas, NumPy, Seaborn, EDA, Univariate & Bivariate Analysis  

---

### 3. MovieLens Dashboard Analysis (Power BI)

Developed interactive dashboards in Power BI using the MovieLens dataset to analyze movie release trends, genre popularity, user demographics, and rating behavior.  
Created DAX measures, applied data modeling techniques, and enhanced reporting with slicers and advanced filtering for deeper insights.

**Tools & Skills:** Power BI, DAX, Data Modeling, Dashboard Development, Data Visualization
