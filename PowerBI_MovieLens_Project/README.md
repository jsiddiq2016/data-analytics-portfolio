# Power BI Project – MovieLens Dashboard Analysis

This project analyzes the MovieLens dataset (1900–2000) using Power BI to explore:

- Genre popularity and movie distribution  
- User demographics (age, gender, occupation)  
- Rating patterns over time  
- Top-rated movies and genres  

## Key Insights for each Dashboard Pages:

### Home Page – Overview KPIs and Genre Insights
- The dataset contains 3,883 movies across 18 genres and 6,000+ users.
- Drama and Comedy-based genres appear most frequently.
- Ratings average around 3.6–3.8, showing strong overall satisfaction.
  
### Second Page – Top Rated Movies and Rating Trends
- Several movies stand out as consistently top-rated.
- Ratings remain stable over time with slight genre variation.
- Users aged 55+ provide the highest average ratings.

### Third Page – User Demographics and Geographic Distribution
- Users aged 25–34 represent the most active segment.
- Engagement is concentrated in North America.
- Ratings vary across occupations, supporting demographic-based personalization.
